# Model Card

## Model Details

This model is a Random Forest Classifier developed using Scikit-Learn. The model predicts whether an individual's annual income is greater than $50,000 based on demographic and employment-related attributes from the Census Income dataset.

## Intended Use

The model is intended for educational purposes as part of the Udacity Machine Learning DevOps Engineer Nanodegree. It demonstrates a complete machine learning workflow including data processing, model training, model evaluation, deployment with FastAPI, and continuous integration.

The model should not be used to make real hiring, compensation, lending, housing, or other high-impact decisions involving individuals.

## Training Data

The training data comes from the Census Income dataset (`census.csv`) provided with the project. The dataset contains demographic and employment information such as age, education, occupation, relationship status, race, sex, workclass, and hours worked per week.

The data was split into training and testing datasets using an 80/20 train-test split.

## Evaluation Data

The evaluation dataset consists of the 20% held-out test set generated using Scikit-Learn's `train_test_split()` function. This dataset was not used during model training and was reserved for model evaluation.

## Metrics

The model was evaluated using:

- Precision
- Recall
- F1 Score

Model performance:

- Precision: 0.7419
- Recall: 0.6384
- F1 Score: 0.6863

In addition to overall performance metrics, performance was evaluated across categorical feature slices and recorded in `slice_output.txt`.

## Ethical Considerations

This dataset contains demographic attributes including race, sex, marital status, and nationality. Models trained on these features may learn historical biases present in the underlying data.

Predictions generated by this model may therefore contain unfair or discriminatory patterns. Care should be taken when interpreting results, and the model should not be used for real-world decisions affecting employment, compensation, credit approvals, housing, or legal outcomes.

## Caveats and Recommendations

This model was developed for educational purposes and has several limitations:

- It was trained on historical census data and may not reflect current economic conditions.
- Performance metrics indicate prediction errors are still present.
- The model has not undergone fairness testing beyond categorical slice evaluation.
- Additional hyperparameter tuning and feature engineering may improve performance.
- Further bias and fairness analysis should be conducted before using similar models in production environments.
